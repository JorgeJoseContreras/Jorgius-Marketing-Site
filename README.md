## 🌟 Key Features & Design Highlights

- **Dynamic Interactive Background**: Canvas-powered particle constellation network that responds dynamically to cursor movements.
- **Kinetic Text Effects & Hover Glows**: Shimmering gradient headlines and interactive magnet text hovers.
- **3D Perspective Tilt Cards**: Feature cards, pricing plans, and step containers feature custom 3D rotation physics with radial spotlight reflections following mouse coordinates.
- **Interactive iMessage Playground**: Embedded iPhone mockup demonstrating real-time blue/gray chat bubbles, prompt pills, typing animations, and simulated AI responses.
- **Sleek Obsidian Dark Aesthetics**: Curated dark theme palette built with glassmorphism overlays and neon purple/cyan accents.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```
